# Relevo operativo

No hay tarea real activa, editor saliente ni destinatario confirmado. La instalación no autoriza cambios de producto.

## Formato de una tarea autorizada

- Tarea, objetivo y alcance autorizado.
- Hechos comprobados, cambios propios y cambios preexistentes.
- Verificaciones realizadas, pendientes y resultado.
- Estrategias, intentos fallidos y acciones que no deben repetirse.
- Operaciones de resultado desconocido, bloqueos y decisiones humanas necesarias.
- Primera acción concreta para continuar.
- Editor saliente, destinatario propuesto y confirmación humana de transferencia.

Mantenerlo breve, enlazar evidencia persistente cuando exista y no copiar secretos ni transcripciones.
